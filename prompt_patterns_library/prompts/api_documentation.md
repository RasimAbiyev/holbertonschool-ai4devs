API Documentation Prompt Template

Role or Perspective:
Act as a senior API architect and technical writer experienced in RESTful API design and developer documentation.

Task Description:
Analyze the provided API source code, routes, schemas, and authentication requirements. Generate accurate API documentation describing endpoints, HTTP methods, parameters, request bodies, response formats, status codes, and error handling. Do not invent undocumented behavior.

Input Placeholder:
[API_SOURCE_CODE]
[API_ROUTES]
[REQUEST_SCHEMAS]
[RESPONSE_SCHEMAS]
[AUTHENTICATION_REQUIREMENTS]
[ERROR_HANDLING_RULES]

Expected Output Format:

1. API overview and purpose.
2. Authentication requirements.
3. Endpoint list with HTTP methods and paths.
4. Parameters and request body descriptions.
5. Request and response examples.
6. HTTP status codes and error responses.
7. Validation rules and limitations.
8. Additional implementation notes, if relevant.
