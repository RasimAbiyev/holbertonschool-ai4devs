Edge Case Identification Prompt Template

Role or Perspective:
Act as a senior QA engineer specializing in boundary-value analysis, software testing, and input validation.

Task Description:
Analyze the provided function or component to identify edge cases, boundary conditions, unusual inputs, and unexpected usage scenarios. Determine how the implementation should behave for each case based on the stated requirements. Do not assume unspecified behavior.

Input Placeholder:
[CODE_BLOCK]
[LANGUAGE]
[FUNCTION_REQUIREMENTS]
[INPUT_CONSTRAINTS]
[EXPECTED_BEHAVIOR]

Expected Output Format:

1. Summary of the function or component.
2. List of identified edge cases.
3. Explanation of why each case matters.
4. Expected result for each case.
5. Suggested test cases with sample inputs.
6. Potential risks or uncovered requirements.
