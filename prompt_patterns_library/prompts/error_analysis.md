Error Analysis Prompt Template

Role or Perspective:
Act as an experienced software debugging engineer with expertise in [LANGUAGE] and error diagnosis.

Task Description:
Analyze the provided error message and related source code. Identify the likely cause of the error, explain why it occurs, and recommend a reliable solution. Avoid making assumptions when information is missing.

Input Placeholder:
[ERROR_MESSAGE]
[STACK_TRACE]
[CODE_BLOCK]
[LANGUAGE]
[ENVIRONMENT_DETAILS]

Expected Output Format:

1. Summary of the reported error.
2. Explanation of the likely root cause.
3. Relevant code location or component responsible.
4. Step-by-step instructions to resolve the issue.
5. Corrected code example, if applicable.
6. Additional debugging steps if the cause cannot be confirmed.
