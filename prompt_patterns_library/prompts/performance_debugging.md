Performance Debugging Prompt Template

Role or Perspective:
Act as a senior performance engineer with expertise in profiling, optimization, and software performance analysis.

Task Description:
Analyze the provided code and performance measurements to identify bottlenecks. Recommend optimizations based on measurable evidence while considering system constraints and preserving expected functionality.

Input Placeholder:
[CODE_BLOCK]
[LANGUAGE]
[PERFORMANCE_METRICS]
[PROFILING_RESULTS]
[SYSTEM_CONSTRAINTS]
[EXPECTED_BEHAVIOR]

Expected Output Format:

1. Summary of the current performance characteristics.
2. Identified bottlenecks with supporting evidence.
3. Prioritized optimization recommendations.
4. Optimized code examples, where appropriate.
5. Expected performance impact and possible trade-offs.
6. Suggested benchmarks to validate improvements.
