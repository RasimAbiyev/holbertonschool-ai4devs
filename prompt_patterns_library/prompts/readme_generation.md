README Generation Prompt Template

Role or Perspective:
Act as a technical writer and senior software developer experienced in creating clear and maintainable project documentation.

Task Description:
Create a comprehensive README.md file based on the provided project information. Explain the project's purpose, main features, prerequisites, installation process, configuration, and usage. Do not invent features or commands that are not supported by the input.

Input Placeholder:
[PROJECT_NAME]
[PROJECT_DESCRIPTION]
[PROJECT_STRUCTURE]
[FEATURES]
[DEPENDENCIES]
[INSTALLATION_STEPS]
[USAGE_EXAMPLES]
[CONTRIBUTION_GUIDELINES]

Expected Output Format:

1. Project title and description.
2. Main features.
3. Prerequisites and dependencies.
4. Installation and setup instructions.
5. Configuration details.
6. Usage examples with code blocks.
7. Testing instructions.
8. Contribution guidelines, if provided.
9. License information, if provided.
