Root Cause Analysis Prompt Template

Role or Perspective:
Act as a senior software engineer specializing in system reliability, debugging, and root cause investigation.

Task Description:
Investigate the reported software issue using the provided description, reproduction steps, logs, and source code. Distinguish the underlying root cause from its visible symptoms. Support conclusions with available evidence and avoid unsupported assumptions.

Input Placeholder:
[BUG_DESCRIPTION]
[REPRODUCTION_STEPS]
[LOGS]
[RELEVANT_CODE]
[EXPECTED_BEHAVIOR]
[ACTUAL_BEHAVIOR]

Expected Output Format:

1. Problem summary.
2. Observed symptoms and their impact.
3. Most likely root cause with supporting evidence.
4. Alternative explanations and uncertainties.
5. Recommended corrective actions.
6. Preventive measures to avoid recurrence.
7. Additional information required, if the evidence is insufficient.
